# 🛡️ Insurance Management System

## 📌 Project Overview

The Insurance Management System is a console-based Java application developed
to demonstrate Object-Oriented Programming (OOP) concepts through different
types of insurance policies.

The application provides a menu-driven interface for exploring and managing
insurance policy options.

## ✨ Features

- 🏥 Health Insurance
- 🏠 Home Insurance
- ❤️ Life Insurance
- 🚗 Vehicle Insurance
- ✅ Input validation
- 📋 Menu-driven console interface
- 🔄 Object-Oriented Programming implementation

## 🛠️ Technologies Used

- Java
- Core Java
- Eclipse IDE

## 🧠 Java Concepts Used

- Classes and Objects
- Inheritance
- Polymorphism
- Method Overriding
- Encapsulation
- Exception Handling and Input Validation
